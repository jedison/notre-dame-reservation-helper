# Security policy

## Supported version

Security fixes are made against the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a potential vulnerability. Use this
repository's **Security** tab to create a private vulnerability report.

Include a minimal, non-sensitive reproduction and the potential impact. Never
include reservation references, names, contact details, cookies, session data,
or Cloudflare/CAPTCHA material. Acknowledgement and next steps will be shared
through the private report.
